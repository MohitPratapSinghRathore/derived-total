# Coherent Errors

**Chess Transformers Play Correctly on Misremembered Boards.**

When a search-free chess transformer plays an illegal move, it is usually playing
a *legal* move in the board it believes it is in. The errors are coherent, the
belief is causally load-bearing, and both properties strengthen with model size
over the range we can train.

## What is measured

All numbers come from `results/*.json` and reach the manuscript only through
`\result{}` macros generated by `code/make_macros.py`. Nothing in the paper is
typed by hand.

| finding | evidence |
|---|---|
| Errors are coherent | 35.6% of illegal moves are legal in the model's own decoded board, against 5.0% for the same move under another position's belief and 0.8% for an arbitrary illegal move. Ceiling 65.7% |
| The belief is read, not merely present | Editing one probe direction removes 93% of the probability mass on moves from that square; a norm-matched random edit removes 8% and shifts mass at chance |
| Where you measure matters | Whole-board probe accuracy predicts an illegal move at AUC 0.53 to 0.69; restricted to the squares the move uses, 0.59 to 0.68. Indistinguishable in the opening, separating with depth |
| Both scale | Belief consistency normalised by each model's ceiling rises 0.476 to 0.587 from 3.4M to 39.9M parameters, three seeds per rung, while the control stays flat near 0.05 |
| Judgement survives when memory does | Median centipawn loss at ply 30 to 40 falls from 63 to 41, and blunder rate from 0.39 to 0.22, when the board is required to be nearly intact |

## What failed, and is reported as such

- A predicted layer profile that ran backwards: state is most decodable at the
  final block, not mid-stack.
- A pre-registered metric that is degenerate: exact-position fidelity is zero
  past ply 20 in every condition, so it discriminates nothing.
- An auxiliary state objective that raises probe accuracy to the level of a model
  twice the size while buying about an eighth of its horizon gain.
- An ablation that *improves* the illegal-move rate while worsening prediction,
  because the ablated model hedges toward the legal-move prior. This is a caveat
  about the observable, and motivated a horizon defined on fidelity instead.
- Seven task designs before a second domain became measurable
  (`protocol/execution_traces.md` explains what the failures taught).

## Layout

    code/       pipeline: data prep, oracle labelling, model, training,
                probes, coupling, belief, causal patching, engine scoring,
                figures, tables, macros, QA gates
    paper/      main.tex, refs.bib (every entry web-verified), titlepage.tex,
                generated tables.tex and results_macros.tex, figures/
    build/      author PDF, anonymous PDF, title page
    results/    every result JSON plus macro_provenance.json
    protocol/   the pre-registered protocol, and the execution-trace design
                for the third domain

`data/` (PGN dumps, oracle arrays, Stockfish) and `runs/` (checkpoints) are not
tracked. Both regenerate from the code.

## Reproducing

    python code/prep_data.py 120000      # Lichess PGN -> game-split token arrays
    python code/make_states.py train_probe eval train_lm   # rules-engine oracle
    python code/run_grid.py              # the condition grid
    python code/run_analysis.py          # probes, coupling, belief, patching
    python code/ladder_seeds.py          # scale ladder, three seeds per rung
    python code/build_paper.py           # macros, tables, figures, both PDFs
    python code/qa_gates.py              # style and integrity gates

The gates check em-dashes, banned vocabulary, title and abstract length,
undefined references, anonymity of the blind build, that every `\result` key used
is defined, and that the built PDF is newer than its sources. That last one
exists because a build failed silently for a day behind a stale artifact.

## Status

Chess arm complete: six scale rungs at three seeds, four architectural
conditions at three seeds, mechanism tests on every condition. Second domain
(permutation tracking) reaches a measurable regime but only its supervised
condition maintains a decodable state, which is reported as an instrument
finding rather than a replication.

Not done: a natural-language transfer arm. It is absent rather than
approximated. `protocol/execution_traces.md` argues program execution traces are
the better and far cheaper next instrument, and states what would refute the
paper's framing.
